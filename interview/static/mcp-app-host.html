Answer-check card, rendered by a local reference host

Rehearsal's MCP server publishes ui://rehearsal/answer-check (text/html;profile=mcp-app) and links it to check_answer_text and compare_answer_texts. Hosts that support MCP Apps render tool results with that card. This page is a minimal host written for testing: it reads the resource over MCP, loads it in a sandboxed iframe, and speaks the postMessage JSON-RPC protocol. It is not a third-party product.
